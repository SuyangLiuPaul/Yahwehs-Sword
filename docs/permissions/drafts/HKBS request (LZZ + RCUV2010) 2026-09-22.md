**吕振中译本 is not public domain.** Lü Zhenzhong died in 1988; under the
life+50-years rule used across HK/Taiwan/mainland China, the translation
stays in copyright until roughly 2038. Wikisource's own entry for it
(https://zh.wikisource.org/zh-hans/圣经_(吕振中译本)) is a bare chapter
index with every chapter a red link — no text actually hosted — which is
consistent with it not being free yet rather than evidence either way.

**和合本2010 / RCUV** is HKBS's current commercial edition (2010), under
active copyright with no public-domain argument at all.

尊敬的香港圣经公会版权部：

您好。我们是《雅伟的话》（Yahweh's Words）团队，制作了两款免费圣经应用 ——
《雅伟的话》（yahwehword.com）与《雅伟之剑》（Yahweh's Sword，

Publishers 于 2017 年授权）等多个译本。

现诚挚申请贵会以下两个译本的非独家数字版权，用于在上述应用中呈现全文：

1. 吕振中译本（吕振中牧师翻译，1970 年由贵会资助出版）
2. 和合本2010（和合本修订版）（贵会 2010 年出版）

申请范围：
- 仅限数字/应用形式使用，不涉及纸质印刷
- 全球发行，不限地区
- 应用本身及所载经文文本永久免费，不向用户收费
- 若日后应用变为收费产品，本授权即自动终止（与贵会通常的免费条款一致）

我们承诺：
- 在应用「关于」页面完整呈现贵会指定的版权声明文字，一字不改
- 若贵会要求，可对单次经文摘录/分享设置节数上限（如贵会认为必要）
- 提供最终应用截图或安装包供贵会审核确认呈现方式

烦请告知贵会的正式申请流程（表格/条款），或直接以邮件回复本申请的意向。如需进一步资料（应用介绍、现有授权范例等），我们可随时补充。
